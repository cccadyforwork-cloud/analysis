# 货盘动销分析工作台

这是一个单文件静态网页工作台，用于分析 Amazon Business Report CSV 的货盘动销表现。当前主页面为 `货盘动销分析_WK29-WK30_可下载版.html`，已合并 Horizon UI 负责人版界面。

## 功能

- 运营行动（默认首页）：上传近 30 天 Business Report CSV，形成三类互斥队列：头部产品先看双周趋势和库存覆盖，再规划新增变体；Sessions ≥10 且销量 1–5 件的产品优化链接；销量为 0 的产品不论曝光多少均进入零销量队列。1 店候选须在本店可售 Listing 中出现且 FBA 可售库存大于 0；行动可记录库存核实、父 ASIN、计划变体、执行人、截止日期和复盘，并导出 CSV 台账或版本化 JSON。
- 货盘全量：默认用 1 店可售 Listing 与近 31 天业务报告查看候选 ASIN 的 GV、Sessions、销量、销售额和产品明细；运营行动候选可直接跳转到对应货盘详情。也支持上传 Listing 和其他业务报告；两个排行默认显示前 5 个，展开后每页 50 条，明细每页 50 条。
- 周对周报告：上传当前周和对比周 CSV，生成曝光、销量、销售额、ASP、动销 ASIN 等核心指标。
- 品类占比：按 1 店最新可售 Listing 的 ASIN 数计算一级分类占比，饼图图例展示全部一级分类；每个一级分类都有对应的二级分类坐标柱状图，横轴列出全部二级分类，纵轴显示百分比，0% 分类以灰色标注。
- 多周趋势：一次上传 2 个及以上 CSV，查看 GV、Units、Sales、ASP、AWAS 和动销率趋势。
- 负责人筛选：按负责人查看匹配的 ASIN、库存、近 7 日销量和行动建议。
- 价格段分析：按 ASP 价格段拆分出单 ASIN、曝光、销量和客单价。
- 库存动销结构：区分动销和不动销 ASIN 对应库存。
- 导出 Excel：主要报告区块支持导出明细或汇总。
- 内置周对周报告：1 店 2026-09-12 至 09-19 对比 09-20 至 09-27，两段均为 8 天；按 2026-10-05 的可售 Listing（FBA 可售 > 0）过滤。旧 WK29/WK28 数据仍可通过「查看旧示例」单独预览。多周趋势默认显示这两段最新数据。
- 外观主题：页首提供浅色 / 深色切换，选择会保存在当前浏览器。

## 使用方式

直接双击 HTML 文件可以打开；推荐用本地静态服务打开，浏览器兼容性更稳定：

```bash
python3 -m http.server 18765 --bind 127.0.0.1
```

然后访问：

```text
http://127.0.0.1:18765/货盘动销分析_WK29-WK30_可下载版.html
```

## CSV 要求

CSV 来自 Amazon 后台「业务报告 / Business Report」。页面会自动识别常见中英文表头，并兼容包含「子 ASIN」或仅保留 ASIN 的格式。

常用字段包括：

- ASIN 或 子 ASIN
- 标题 / 商品标题
- 页面浏览量 - 总计
- 已订购商品数量
- 已订购商品销售额

价格段基于 `ASP = 销售额 / 销量` 计算。若 CSV 数据为空、字段缺失或两周口径不一致，页面会给出错误提示或生成结果偏差。

## Listing 要求

货盘全量默认使用 1 店 `Listing20261005-2106879747845795841.xlsx` 中 774 个 `FBA可售 > 0` 的 ASIN，并叠加 `BusinessReport-04-10-26.csv` 的 2026-09-03 至 2026-10-03 月报。月报覆盖其中 661 个，另 113 个仅在 Listing 中出现，明细显示「报告未覆盖」，不会视为零销量；月报中 295 个没有本店可售 Listing 依据的 ASIN 已排除。浏览器之前保存的 WK29/WK28 货盘结果会被此默认月报结果替换。运营行动候选行的「查看货盘详情」会切到该 ASIN 的货盘明细。

货盘全量也支持手动上传 `.xlsx`、`.xls` 或 `.csv` 的 Listing / 负责人表，至少需要 `ASIN` 列。可选字段包括 `MSKU`、`SKU`、`标题`、`品名` 和负责人列。上传后可叠加所选业务报告；点击「沿用周对周报告」则切换为周报口径。

Excel 读取依赖本地 `vendor/xlsx.full.min.js`，因此离线打开本地服务时也能解析 `.xlsx` Listing。

「品类占比」按 `data/Haul商品一级二级分类文档.md` 的 13 个一级分类计算，分母为 `Listing20261005-2106879747845795841.xlsx` 中 774 个唯一且 `FBA可售 > 0` 的 ASIN。774 个均已归类；文档没有汽车用品分类，原先待确认的 12 个 ASIN 已按标题字面含义归入最接近的家居清洁、家居装饰或家装工具五金分类。一级饼图图例始终列出 13 类；二级柱状图每个一级分类一张，横轴始终列出文档中的全部二级分类，纵轴为该一级分类内的 ASIN 百分比，0% 分类保留并显示为灰色。逐 ASIN 结果在 `reports/1店_可售ASIN品类_2026-10-05.csv`，分类依据以 Listing 英文标题为主、品名和 MSKU 为辅；若需重算，运行 `python3 scripts/build_haul_category_share.py /path/to/Listing.xlsx`，再运行 `python3 scripts/embed_haul_category_data.py` 将映射写入单文件页面。

「运营行动」页签按店铺和站点保存多份近 30 天业务报告，切换店铺时同步切换候选、负责人、统计与行动台账。内置的 `1店` 报告来自 `BusinessReport-04-10-26.csv`，运营提供的周期为 2026-09-03 至 2026-10-03；站点尚未指定。该报告 962 行按子 ASIN 合并为 956 个 ASIN。后续上传其他店铺报告时须填写店铺标识。页面只检查填写日期约为 30 天，无法从 CSV 独立核验报表实际周期。

运营行动页的「业务报告可售 ASIN」数字卡统计当前店铺整份报告中有可售依据的 ASIN 总数，并按本店 Listing 的「负责人1（业绩归属人）」展示每位负责人的数量；数字不受行动队列或当前负责人筛选影响。点击负责人数字可切换候选筛选，店铺内负责人覆盖分配会同步更新数字。1 店优先使用 `Listing20261005-2106879747845795841.xlsx`：只有业务报告与该 Listing 按 ASIN 直接匹配、且 `FBA可售 > 0` 的 ASIN 才计入可售数量及行动候选；报告中不在该 Listing 的 ASIN 按不可售排除，无需处理。该 Listing 的库存仍是快照，需核对链接实时可售状态。未提供本店 Listing 的其他店铺暂沿用最近 7 天本店人工核实库存优先、否则参考 ASIN 自身全局 FBA 库存的口径。

本次 1 店 Listing 有 775 个唯一 ASIN，其中 774 个 `FBA可售 > 0`；业务报告有 956 个 ASIN，直接匹配 662 个，其中 661 个 `FBA可售 > 0`。仅在业务报告中的 294 个已排除；另有 1 个匹配但 `FBA可售 = 0`，也已排除。仅在 Listing 中的 113 个没有该报告记录，不据此判为零销量。661 个可售匹配 ASIN 按负责人分为图图 282、凯旋 177、公司 132、cccady 47、未分配 23。按当前默认门槛，三类候选分别为头部 85、有曝光低转化 165、零销量 243。完整差异见 `reports/1店_业务报告与可售Listing匹配_2026-10-05.csv`；候选见 `reports/1店_运营候选_2026-09-03_2026-10-03.csv`。

头部候选默认取有库存 ASIN 中本店近 30 天销量前 20% 且至少 5 件；仅在另外上传**本店**上周和本周报告，双周均有销量且本周不低于上周 80% 时才标为稳定。现有全局双周样例不用于判断单店走势。新增变体任务需要目标父 ASIN、约 30 天报告、稳定的本店双周走势，以及最近 7 天内人工核实的本店安全库存（默认覆盖至少 21 天）。有曝光低转化默认门槛为 `Sessions ≥ 10`、`1 ≤ Units ≤ 5`；零销量单独进入下一队列，不再按转化率百分比判断。门槛可在页面调整并保存在当前浏览器。

零销量队列只从当前店铺报告中明确存在且 `Units = 0` 的行产生，Sessions 与 GV 可为任意值；Listing 中有而业务报告中缺行不用于推断本店零销量。1 店按本店可售 Listing 直接匹配；其他店铺在未提供本店 Listing 前暂参考全局库存，且不以子 ASIN 合计库存推断父 ASIN 可售。零销量候选按有无流量排查价格、主图、收录、关键词和链接内容。运营可在当前店铺内覆盖分配负责人；已有行动的执行人单独维护。报告、负责人分配和行动记录保存在当前浏览器的 `localStorage`，内置的 `1店` 报告及 Listing 随 HTML 提供。CSV 台账和 `schemaVersion: 1.2` JSON 均按当前店铺与负责人导出，新零销量路径标识为 `zero_sales`；已保存的旧 `zero_exposure` 行动在本地自动归入该路径。JSON 包含店铺标识、站点、ASIN、MSKU、候选、证据、本店 Listing 匹配与库存参考、规则和任务，供后续店铺运营系统接入。页面不会自动修改 Amazon 链接、价格或广告。

主页面内嵌了结合 `Listing20261004-2106531119390355457.xlsx` 和 `导出产品-按SKU-2106790713500901377.xlsx` 生成的 ASIN → 品名映射。优先采用 Listing 的 ASIN 直连品名；若产品表中的 MSKU 有精确匹配且名称不同，以产品表为准并输出纠错记录。缺失时用产品表的 SKU 或明确的 QS 型号尺码关系补充；同一父 ASIN 下所有子 ASIN 的品名一致时，再继承给父 ASIN。其他冲突或缺少依据的条目不填充。周对周报告、货盘排行与明细优先显示这份品名；1 店运营行动优先使用最新本店 Listing 的品名、MSKU、父 ASIN 和负责人。货盘全量和运营行动支持按品名搜索，行动台账 CSV 也包含品名列。

收到更新的 Listing 与产品表后，可运行 `python3 scripts/refresh_product_names.py /path/to/Listing.xlsx --sku-workbook /path/to/产品表.xlsx` 重新嵌入品名。脚本遇到同一 ASIN 或 SKU 的不同品名会报错。

收到更新的 1 店可售 Listing 后，可运行 `python3 scripts/refresh_store_listing.py /path/to/Listing.xlsx` 更新工作台内嵌的本店 Listing，并重生匹配差异表和候选表。

货盘全量支持负责人筛选，切换负责人后会同步刷新 GV 排行、销量排行、风险卡片和完整货盘明细。两个排行各自可以展开；收起显示前 5 个，展开后每页 50 条，明细每页 50 条。

## 数据说明

页面内嵌了负责人、MSKU、FBA 可售库存和近 7 日销量元数据。该元数据来源注释保留在 HTML 末尾：

```text
SKU+负责人.xlsx + WES SKU+负责人.xlsx（合并于 2026-07-20）
```

如果负责人或库存资料更新，需要重新生成或替换 HTML 内的 `SKU_META` 数据。

周对周报告的负责人筛选以当前业务报告为主，只显示本次报告中实际出现过的负责人，以及 `报告未匹配` ASIN。按钮计数均为报告 ASIN 数；资料库里有但当前报告未出现的负责人或未分配 ASIN 不会单独显示。

内置周对周报告来自 `9月第3周.csv` 和 `9月第四周.csv`。第 3 周原报 677 个 ASIN，其中 514 个匹配可售 Listing；第 4 周原报 623 个，其中 584 个匹配。页面中的周报数量与汇总均按匹配后的 ASIN 计算。可用 `scripts/refresh_wow_report.py` 重新生成内置报告，需明确传入两期的起止日期。

```bash
python3 scripts/refresh_wow_report.py /Users/admin/Desktop/9月第3周.csv /Users/admin/Desktop/9月第四周.csv \
  --previous-start 2026-09-12 --previous-end 2026-09-19 \
  --current-start 2026-09-20 --current-end 2026-09-27
```
